# Nemesis Minifigures — Static Portfolio Demo

This is a self-contained public-facing portfolio copy of the Nemesis Minifigures site.

Run it with any static web server from this folder (for example, `python -m http.server 8080`) and open `http://localhost:8080`.

It includes the public pages, branding, catalog snapshot, and available product media. Admin pages, PocketBase, payment processing, and live customer/order submission are intentionally excluded or disabled.
